# Asian Paints Limited — Financial Analysis & Forecast

## Project Overview

This project presents a financial analysis and forecasting model for Asian Paints Limited, built using Microsoft Excel and Google Sheets. It analyses historical financial performance and develops illustrative forecasts for FY2027E–FY2029E using Bear, Base, and Bull scenarios.

The model combines historical financial analysis, assumption-driven forecasting, scenario analysis, sensitivity analysis, and a dashboard to understand how changes in operating assumptions can affect projected profitability.

## Objectives

- Analyse historical revenue and profitability trends.
- Develop a three-year financial forecast.
- Compare Bear, Base, and Bull operating scenarios.
- Evaluate the sensitivity of FY2029E profit after tax (PAT) to revenue growth and EBITDA margin.
- Present key financial indicators through a dashboard.

## Tools Used

- Microsoft Excel
- Google Sheets
- Spreadsheet formulas, financial modelling, charts, and data visualisation

## Forecasting Methodology

The model uses historical financial performance and selected assumptions to estimate future results.

- **Revenue:** Forecast using the selected annual revenue growth assumption.
- **EBITDA:** Estimated by applying the selected EBITDA margin to forecast revenue.
- **Depreciation and amortisation:** Forecast as a percentage of revenue.
- **Finance costs:** Forecast as a percentage of revenue.
- **Tax expense:** Estimated using the selected effective tax rate.
- **Profit after tax:** Derived from the forecast profit before tax and tax expense.

The model includes three illustrative scenarios:

- **Bear Case:** Conservative operating assumptions.
- **Base Case:** Central assumptions based on the model's historical-ratio approach.
- **Bull Case:** Stronger revenue growth and profitability assumptions.

## Sensitivity Analysis

The sensitivity analysis examines how FY2029E profit after tax changes across different revenue growth and EBITDA margin assumptions, while holding Base Case depreciation and amortisation, finance costs, and tax assumptions constant.

## Key Learning Outcomes

- Building linked financial forecasting models.
- Calculating financial ratios and profitability margins.
- Using scenario analysis to compare alternative outcomes.
- Performing sensitivity analysis.
- Designing a financial dashboard for communicating results.
- Documenting assumptions and model limitations.

## Limitations

- Forecasts are illustrative and depend on the assumptions selected.
- The model is not official company guidance.
- Forecast EBITDA uses revenue multiplied by the assumed EBITDA margin; Other Income is not forecast separately.
- Historical financial figures should be verified against the original company annual reports before external use.
- Actual financial performance may differ materially from projected results.


This project is for educational and portfolio demonstration purposes only. It does not constitute investment advice, a valuation opinion, or a forecast issued by Asian Paints Limited.
